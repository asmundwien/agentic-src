# Repository instructions

Edit source content in this repository, `agentic-src`, not generated collections in the sibling `agentic` repository.

## Guardrails

- Run collection commands from the collection's directory, not the repository root.
- Do not edit `.rulesync/rules/.curated/` or `.rulesync/skills/.curated/`, or copy downloaded content into source control. Rulesync manages these ignored directories.
- Avoid unintended overrides of upstream content. Follow the [local content guidance](README.md#edit-local-content).

## Task references

- When setting up tooling or fetching upstream content, read [Work on collections](README.md#work-on-collections) for prerequisites, commands, and authentication.
- When changing upstream selections, follow [Change upstream selections](README.md#change-upstream-selections).
- When adding a collection, follow [Add a collection](README.md#add-a-collection).
- When editing local rules or skills, follow [Edit local content](README.md#edit-local-content) for file placement, supporting files, and attribution.
- When changing this repository's agent tooling, read [Repository-local agent tooling](README.md#repository-local-agent-tooling).
- When publishing, follow [Publish collections](README.md#publish-collections).
